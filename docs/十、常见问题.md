# 十、常见问题 :id=top

## 半走读
指中午在校住宿、晚上回家休息的上学方式。军训期间学校原则上禁止半走读。
## 校车
校车的路线、票价与购票方式，请移步 [初入一中 - 校车](/docs/一、初入一中.md?id=校车) 查看。

## 学校的饭好吃吗？
学校的食堂都有一些特色菜品是广受好评的，但是家花肯定没有野花香，经常有同学会预订前洪服务区或者步行街的商家。

## 选科、赋分是什么
高一下学期起，学生须从六门副科中选择三门作为高考科目，其余科目不再学习，并且会重新分班。受政策影响，选科并非完全自由，例如物化捆绑。分科后，因各科难度不同，采用赋分制，即按名次赋分：前1%赋100分，随后按名次依次递减，最后1%赋21分。

## 合格考是什么
合格考即学业水平合格性考试，考查学生对必修内容的掌握程度，成绩只有“合格”与“不合格”两种，有科目不合格将无法领取高中毕业证，考试范围基本为必修内容。**高一阶段考化学、生物、历史、地理；高二上学期考数学、外语、语文、政治、物理，下学期考通用技术、信息技术。** 合格考按全省末位约5%的比例划定不合格，故没有固定分数线。如合格考未通过，高考时无法报考相应科目；每次合格考均设有补考机会，未通过也不必过于焦虑，但市级、省级优秀学生评选等活动要求无未合格科目。

## 高考外语怎么考
高考外语可在英语、俄语、日语、德语、法语、西班牙语中任选一门。除英语外，学校仅开设日语学科，由校外机构进校辅导，自高一暑假开始学习，此后每个寒暑假均开课（须参加）。校内采取走班授课：英语课时间，日语生前往日语教室上课。学校现只有远大一家日语机构。

## 高中还能不能入团
可以，但机会有限。入团名额较少，仍可积极争取。
