# 五、宿舍生活篇 :id=top

**保姆级教程 =）**

1. 保持宿舍卫生，虽然宿管不会拉着你干活，但是会扣分

2. 和人好的宿管搞好关系，能免去很多不必要的麻烦，不要和某些逆天宿管生气，也不要和他们发生冲突，**不要因为别人的错误惩罚自己。**

3. 刚到宿舍如果发现床头那个柱子的顶很松，打开看一下，有极小概率会出现一个小瓶子里面装着烟头烟灰口香糖。记得和宿管说或者自己处理掉

4. 有比较迷你的柜子，可能会有学长学姐留下的圣遗物衣架。最好还是自己多带几个

5. 阳台没有晾衣服的地方，你可以挂在床边

6. 几乎完全不会专门查手机，有班主任会在睡觉前来看看，级部极其偶尔会就寝后来查，自己注意。手机事宜详见手机使用指南

7. 你和你室友的友谊大抵是非常真挚的。

8. 有热水，可以泡面，可以把饭带到宿舍，记得及时扔垃圾

9. 床帘或者挡桌子的那种分隔帘大抵是不需要的，蚊帐的话...去问问学校能不能带吧，全宿的可能会用到

10. 夏天别带棉枕头，热死你。

11. 床单的铺法会让你的体验完全不同，有条件可以带几个别针。

12. 大家应该会套被套铺床单吧...要自己铺的

13. 宿舍常备几个没什么用的书和本子，会有大用的

14. 在宿舍存一把伞

15. 宿舍一定要有一台及以上的闹钟

16. **厕所基本都不带门，淋浴间坦诚相见**

17. 记得带一些散热措施，男寝光膀子也可以，要不然夏天会热似，冬天记得及时改厚被子，不然会冻似，办个半宿可以比别的同学多休息很久，会爽似，当然你要是睡过头了，会似。
