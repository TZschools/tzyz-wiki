**位置**：五瑞楼正西侧，一元楼正东面，公共厕所旁边。

**作用**：作为新食堂，缓解了就餐压力。

##### 提示

1. 炒面 7元，含有少量碎鸡柳与麻汁；分量较之前减少，可放两三勺醋混合吃，味道更好。
2. 炒面和炒饭分量整体较以前削弱，没有以前那么顶饱。
3. 盖浇饭 = 素菜 + 奥尔良鸭腿 / 鸡肉 / 其他荤菜（仅肉菜，无素菜配荤菜叠加），10元/份。
4. 牛肉汤的牛肉比过去多，但仍属一般；买牛肉汤会送一张酱香饼。
5. 酱香饼是热门小吃，每日限量，下课大约 3 分钟就会售罄，建议提前去排队。

##### 提示

1. 一楼的炸鸡腿不如奥尔良鸡腿好吃。
2. 二楼米饭套餐的浇菜多为土豆块烧鸡，吃腻了可以只买一碗米饭，去三楼打菜。
3. 总体而言，老食堂的性价比高于新食堂。
4. 鸡蛋灌饼口感偏硬（被形容"硬得跟钢筋一样"）。
5. 葱油饼火候不稳，时好时坏。
6. 肉包子齁咸，且多为极品大肥肉。
7. 玉米6元只有很小半根，地瓜按大小算钱（极易被宰），不推荐。
8. 掉渣饼4.5元/个，分量不够一顿饭，不推荐。
9. 住宿生不要拿着水壶去教学楼接洗漱用的热水，直接在老食堂后面接洗漱用水即可。
