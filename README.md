**阅读前须知：**

1. 这份文档是已经毕业的一中学长学姐，写给新入学和在校同学们的。我们把亲身经验整理下来，希望能够代代传递，帮助学弟学妹更快更好的融入校园、拓宽视野。

2. 每一届学生，都会经历相似的迷茫。很多人对目标和规划没有清晰概念，而往届的经验很难传递下去：一种学习方法是否可行，往往只能自己亲身试错。前人踩过的坑、总结出的心得，大多没能留给下一届，不少同学只能盲目摸索。这也是我们整理这份文档的初衷。此外，也请各位学弟学妹以自身学业为重，本文内容仅作学习参考。

3. 对于来稿，我们将在确保合法合规、客观真实的前提下，将其纳入本文档中。目前，本文档所有区域都开放投稿，希望大家多多参与。**所有投稿同学的个人账号与隐私都会严格保密，不会透露给任何人**。征得同意后，我们会在特别鸣谢中展示（可选择匿名展示）。  
  
   **投稿方式：**

   1. 由一中万能墙代为转达：直接私信发送给万能墙即可，发送内容请尽量包含署名（可非真名）、所投稿区域的章节及章节下的小节。
   > 滕州一中万能墙 <QQ: 717077565>

   2. 直接发送至邮箱：将稿件发送至 [thanatosxy@foxmail.com](mailto:thanatosxy@foxmail.com) ，正文请尽量包含署名（可非真名）、所投稿区域的章节及章节下的小节。
   
   3. 将稿件提交至[Github仓库](https://github.com/TZschools/tzyz-wiki)的issue区

  **为避免重复和保证文档可读性，可能会将几篇来稿进行合成和语言润色，主编们也有自己的学业，更新时间不固定，请大家理解。**
